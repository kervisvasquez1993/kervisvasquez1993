### About Me

Full Stack Developer with 7+ years building production-ready web and mobile applications. Backend with **PHP/Laravel**, **TypeScript/NestJS** and **Java/Spring Boot**; frontend with **React/Next.js**; mobile with **React Native** and **Flutter**.

I apply the same architecture everywhere — **Clean Architecture, DDD and Hexagonal (Ports & Adapters)** — whether it's a Laravel service, a NestJS gateway, a Spring Boot module or a Flutter app (domain · application · infrastructure · presentation, Riverpod as DI). Strong focus on microservices, modular monoliths and maintainable, testable code.

👉 More details, case studies and contact: **[kervisvasquez.site](https://www.kervisvasquez.site/)**

### Architecture & Patterns

```
📐 Clean / Hexagonal     →  DDD · Ports & Adapters · Aggregates · Value Objects · UseCases · DTOs
🔀 Microservices         →  NestJS Gateway + Laravel / Spring Boot services + RabbitMQ
🧩 Modular Monolith      →  Spring Boot · one module per bounded context · public facades
📱 Mobile (same DDD)     →  Flutter (Riverpod · go_router · Dio) · React Native (React Query · Zustand)
🗄️ Data                  →  PostgreSQL · JPA/Hibernate · Flyway · Eloquent · Drizzle
🧪 Testing               →  JUnit 5 · Mockito · Vitest · PHPUnit · flutter_test
🏗️ Design Patterns       →  Repository · Service · Compound Components · Saga Pattern
🔐 Authentication        →  Laravel Sanctum/Passport · Better Auth · JWT
📦 CI/CD                 →  Docker · Dokploy · Cloudflare · GitHub Actions
```
